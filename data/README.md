# APWA Data Directory: Corpus Schemas, Serialized R Objects, & Archival Governance

This directory stores the URL indices, exclusion logs, synchronized Tidyverse corpus tables, and serialized **Structural Topic Modeling (`stm`)** R objects (`.rds`) generated by the `APWA_Scrape_and_STM.ipynb` replication pipeline.

---

## 1. Ethical & Copyright Governance (Why `apwa_parsed_archive.jsonl` is Purged)

The essays in the **American Prison Writing Archive (APWA)** (`https://prisonwitness.org/`) are the intellectual and creative property of incarcerated and formerly incarcerated authors, stewarded by the Johns Hopkins University Sheridan Libraries.

To balance **computational reproducibility** with **archival ethics and storage efficiency**:
1. During live execution in Google Colaboratory (**Script 02**), raw HTML transcripts and metadata blocks are scraped into a temporary workspace file (`apwa_parsed_archive.jsonl`).
2. **Script 03** ingests `apwa_parsed_archive.jsonl`, performs temporal normalization and lemmatization, and serializes the 1:1 aligned R objects (`apwa_clean_corpus.rds` and `apwa_stm_out_object.rds`).
3. In **Step 10A**, once the pipeline verifies that `apwa_clean_corpus.rds` and `apwa_stm_out_object.rds` are safely written to `data/`, the raw bulk `apwa_parsed_archive.jsonl` file is **automatically purged** (`PURGE_RAW_JSONL = True`). This prevents accidental redistribution of raw bulk JSONL dumps in public Git repositories while preserving 100% mathematical reproducibility of all downstream R scripts (`04`–`09`).

## 2. Inventory of Data Files & Object Schemas

### A. Web Scraping & Archival Index Logs (CSV)

#### 1. `apwa_master_urls.csv`
* **Generated by:** `Script 01 (01_index_apwa_urls.py)`
* **Dimensions:** `4,550` rows $\times$ `2` columns
* **Description:** Complete deduplicated index of all unique essay URLs discovered across all `182` active pagination pages of `https://prisonwitness.org/the-archive/`.
* **Schema:**
  * `source_page` (`int`): Archive pagination page number (`1`–`182`) where the essay URL was first indexed.
  * `essay_url` (`str`): Absolute URL to the individual APWA essay page (`https://prisonwitness.org/apwa-essay/...`).

#### 2. `apwa_excluded_urls.csv`
* **Generated by:** `Script 02 (02_scrape_apwa_archive.py)`
* **Dimensions:** `836` rows $\times$ `2` columns
* **Description:** Audit log of APWA URLs that were excluded during scraping because they lacked a machine-readable typed transcript (e.g., handwritten PDF/image scan-only pages) or returned a permanent HTTP 404.
* **Schema:**
  * `excluded_url` (`str`): Absolute URL of the excluded page.
  * `reason` (`str`): Explicit DOM heuristic exclusion reason (`"No Transcript (PDF/Scan Only)"`, `"Empty Transcript"`, `"No Details Block"`, or `"HTTP 404 Not Found"`).

---

### B. Preprocessed Corpus & STM Mathematical Matrix Objects (R `.rds`)

#### 3. `apwa_clean_corpus.rds`
* **Generated by:** `Script 03 (03_tidy_preprocessing.R)`
* **R Object Class:** `tbl_df` / `data.frame`
* **Dimensions:** `3,713` rows $\times$ `6` columns (sorted alphabetically by `slug` and 1:1 row-aligned with `apwa_stm_out_object.rds`)
* **Schema:**
  * `slug` (`chr`): Unique URL slug identifier for the essay (primary key, sorted `A`–`Z`).
  * `url` (`chr`): Full canonical URL on `prisonwitness.org`.
  * `clean_year` (`int`): Verified 4-digit authorship year extracted via regex `\b(19|20)\d{2}\b` and bounded to `[1965, 2026]`.
  * `date_raw` (`chr`): Original unparsed `"Date"` string from the APWA metadata block.
  * `transcript` (`chr`): Original un-lemmatized, un-pruned essay text (used by `stm::findThoughts()` in Script 06 for qualitative exemplar extraction).
  * `cleaned_text` (`chr`): Space-delimited string of domain-guarded lemmatized tokens (`>= 3` alphabetic characters) after both pre- and post-lemmatization ("Plural Bypass") stop-word removal.

#### 4. `apwa_stm_out_object.rds`
* **Generated by:** `Script 03 (03_tidy_preprocessing.R)` via `stm::prepDocuments(..., lower.thresh = 1)`
* **R Object Class:** `list` (standard `stm` input structure)
* **Corpus Dimensions:** `3,713` documents, `24,845` unique vocabulary terms (lemmas), and `1,013,949` total tokens (`26,371` hapax legomena pruned).
* **List Components:**
  * `out$documents`: List of length `3,713`, where each element is a $2 \times N_d$ integer matrix (Row 1 = 1-indexed vocabulary ID; Row 2 = within-document token count).
  * `out$vocab`: Character vector of length `24,845` containing the ordered unique lemmas.
  * `out$meta`: Data frame of dimension `3,713` $\times$ `6` containing document-level covariates (`slug`, `url`, `clean_year`, `date_raw`, `transcript`, `cleaned_text`).

### C. Hyperparameter Tuning & Converged STM Model Objects (R `.rds`)

#### 5. `apwa_searchK_heldout_split.rds`
* **Generated by:** `Script 04 (04_stm_searchK_diagnostics.R)` via `stm::make.heldout(seed = 42)`
* **Description:** Deterministic out-of-sample evaluation split holding out 50% of word tokens in 10% of documents (`N = 371` held-out documents) so all candidate models ($K \in \{10, 20, 30, 40, 50, 60\}$) are evaluated on the exact same held-out words.

#### 6. `apwa_searchK_checkpoint.rds` & `apwa_searchK_results.rds`
* **Generated by:** `Script 04 (04_stm_searchK_diagnostics.R)`
* **R Object Class:** `list` / `searchK`
* **Description:** Stores the model-level summary metrics (`K`, `heldout`, `residual`, `semcoh`, `exclus`, `bound`, `lbound`, `em.its`, `minutes`) and topic-level Semantic Coherence and FREX Exclusivity distributions across $K \in \{10, 20, 30, 40, 50, 60\}$.

#### 7. `apwa_stm_model_k40_final.rds`
* **Generated by:** `Script 05 (05_stm_model_training_k40.R)`
* **R Object Class:** `STM`
* **Specification:** $K = 40$, `prevalence = ~ s(clean_year)`, `init.type = "Spectral"`, converged in `76` EM iterations.
* **Key Sub-Objects:**
  * `final_model$theta`: $3,713 \times 40$ posterior document-topic proportion matrix ($\theta_{d,k}$), where each row sums to `1.0`.
  * `final_model$beta$logbeta[[1]]`: $40 \times 24,845$ log-probability topic-word matrix ($\log \beta_{k,v}$).

#### 8. `resolved_target_topics_k40.rds`
* **Generated by:** `Script 06 (06_qualitative_validation.R)`
* **R Object Class:** `tbl_df` (`7` rows $\times$ `6` columns)
* **Description:** Stores the dynamically verified topic integers (`Resolved_Topic`) mapped via $\beta$-matrix anchor-word scoring for `T_CONNECTION` (`Topic 04`), `T_UTILITY` (`Topic 34`), `T_SURVEILLANCE` (`Topic 10`), `T_COVID` (`Topic 38`), `T_COMMISSARY` (`Topic 24`), `T_ECONOMY` (`Topic 22`), and `T_REENTRY` (`Topic 32`).

#### 9. `apwa_prep_tripartite_effects.rds` & `apwa_topic_correlations.rds`
* **Generated by:** `Script 07` (`stm::estimateEffect`) and `Script 09` (`stm::topicCorr`)
* **Description:** Serialized B-spline temporal prevalence effect estimates (`uncertainty = "Global"`) and the $40 \times 40$ positive topic correlation adjacency matrix (`posadj`, `cor`).

## 3. Quick-Load Example in R

To load the converged model and corpus in R without re-running the scraper or training loop:

```r
library(tidyverse)
library(stm)

final_model  <- readRDS("data/apwa_stm_model_k40_final.rds")
topic_map    <- readRDS("data/resolved_target_topics_k40.rds")

print(topic_map)
```
